최근 기록

이 버전은 데이터가 현재 브라우저에만 저장돼. 기기 변경·Safari 데이터 삭제 시 사라질 수 있으니 설정에서 주기적으로 백업해줘.

바코드 입출고

카메라를 준비하고 있어.

카메라 화면은 크게 보이고, 가운데 가이드 영역 안에서 우선 인식해. CODE128 바코드를 가로 방향으로 맞추고 15~25cm 거리에서 천천히 이동해봐.

상품을 선택하거나 바코드를 스캔해줘.

불량 반품은 판매 가능 재고를 늘리지 않고 별도 불량 수량으로 기록돼. 출고는 재고가 부족하면 등록되지 않아.

상품별 재고

새 상품 등록

코드를 변경하면 기존 라벨 바코드는 사용할 수 없어. 기존 작업 이력은 새 코드로 연결돼.

동일 상품의 컬러나 사이즈가 다르면 각각 다른 코드를 등록해줘. 처음 재고는 상품 등록 후 '입고'로 넣어야 이력에 남아.

작업 이력

☁ 구글 시트 자동 연동

연결 후에는 구글 시트가 기준이야. 아이폰 백업은 이미 시트로 옮겼으므로 다시 업로드하지 않아. 비밀 연결 키는 각 기기에서 한 번씩 입력해줘.

미연결 · 현재 이 기기의 데이터만 표시 중

※ 연결 키는 GitHub 파일에 포함되지 않고 현재 기기 브라우저에만 저장돼. 다른 사람과 기기를 공유하지 마. 연결 중 실패하면 재고를 임의로 변경하지 않고 오류를 표시해.

바코드 라벨 출력

폼텍 LS-3104 전용 (A4 27칸, 62.7 × 30.1mm)이야. 이미 사용한 라벨이 있으면 첫 장에서 건너뛸 칸 수를 지정할 수 있어. 인쇄 시작점은 왼쪽 8.4mm / 위쪽 11mm, 가로 칸 간격은 2.5mm야. 바코드는 라벨 내부에서 54×12mm로 출력돼. 상품을 검색·선택하고 필요한 라벨 수량을 적은 뒤 출력 목록에 추가해줘. 여러 상품을 순서대로 추가할 수 있어. 먼저 일반 A4로 100% 시험 인쇄해줘.

출력 목록

출력할 상품을 선택해서 추가해 줘.

선택된 라벨 0개

상단부터 사용한 개수 입력 · 6을 입력하면 7번째 칸부터 출력

왼쪽 위부터 오른쪽 방향으로 1, 2, 3번, 다음 줄 4, 5, 6번 순서야. 두 번째 장부터는 첫 칸부터 출력해.

+는 오른쪽, −는 왼쪽 · 처음에는 0mm로 시험해 봐

3열 전체가 같은 방향으로 치우쳤을 때 조정해 줘. 상품 및 재고 데이터에는 영향을 주지 않아.

왼쪽 열은 왼쪽으로, 오른쪽 열은 오른쪽으로 · 가운데 열은 그대로

기본값은 0mm야. 20~30mm처럼 큰 값을 지정하면 라벨 밖으로 벗어날 수 있어. 라벨지 대신 일반 A4로 먼저 시험 인쇄하고 0~30mm 사이에서 조절해줘.
